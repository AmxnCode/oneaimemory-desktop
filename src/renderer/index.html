AI session memory

Lets OneAIMemory read your local Claude Code, Codex CLI and Gemini CLI session logs, so any connected AI can pick up real context from conversations you've already had elsewhere — see it under the Memory tab.

This is real conversation content, not just metadata. Off by default, unlike everything else on this page. Secrets and API keys are scrubbed before anything is stored or synced, but the substance of what you discussed is not.

AI access

Which tools can read your consciousness.

Embedded MCP Server

The MCP server runs inside this app and starts automatically when you sign in. AI tools connect to it via ~/.oneconscious/mcp.json to access your activity context.

Loading...
Access binds to a token, not a model name. An MCP server authenticates the credential it is handed — it cannot verify which AI is calling. Revoking the token is the only real revocation.

Remote AI Access

For AI tools that can't run locally, like ChatGPT — they connect to OneAIMemory's server over the internet instead of to this Mac.

This is different from the embedded MCP server above. Turning it on sends a copy of your encryption key to OneAIMemory's servers, so they can decrypt your activity to answer remote AI tools. Your local AI tools (Claude, Cursor, Kiro) are not affected and stay fully encrypted either way.
